## 后端开发面试题

### Python/Django
Q: Django 的请求生命周期
A: 浏览器请求 → WSGI/Nginx 接收 → 中间件链（request 阶段）→ URL 路由匹配 → 视图函数 → ORM 查数据库 → 模板渲染 → 中间件链（response 阶段）→ 返回 HTTP 响应。

Q: Python 装饰器的原理
A: 装饰器本质是闭包，接收函数作为参数，返回新函数。@decorator 语法等价于 func = decorator(func)。常见用途：日志记录、权限校验、缓存、计时。

### 数据库
Q: MySQL 索引原理
A: 默认使用 B+ 树索引。B+ 树所有数据存在叶子节点，叶子节点之间用双向链表连接，支持范围查询。主键索引（聚簇索引）叶子节点存完整行数据；二级索引叶子节点存主键值，需要回表查询。联合索引遵循最左前缀原则。

Q: Redis 常见数据结构及应用场景
A: String（缓存、计数器）、Hash（对象存储）、List（消息队列、最新列表）、Set（去重、共同好友）、Sorted Set（排行榜、延迟队列）、Bitmap（签到统计）、HyperLogLog（UV 统计）。
