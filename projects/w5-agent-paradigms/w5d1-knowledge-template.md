# W5 Day 1 — Agent 三范式 自问自答

## Q1：ReAct 的循环结构怎么写？谁决定下一步做什么？
react的循环结构是思考 → 行动 → 观察 → 思考 → 行动 → 观察 → 回答
response调用llm先思考，msg.tool_calls再执行



## Q2：Plan-then-Execute 和 ReAct 最核心的区别是什么？（代码层面）
区别在于，p-t-e上来先不调用工具只思考并生成路线图后再按照路线图进行，react是思考并调用工具在思考在调用工具一次一次直到循环结束



## Q3：Plan-Execute 方式 B（逐步骤）和方式 C（一句话指令）各有什么优缺点？
方式b优势是过程透明全由代码控制，缺点是过程太详细可能会导致输出变慢
方式c优势是有路线图之后llm能自主搜索，缺点是llm自主可能会丢失一些信息



## Q4：Reflexion 的两轮循环是怎么衔接的？反思提示放在哪个位置？
两轮循环是将第一轮循环得到的答案让大模型自己检查并补充，反思要放在两轮for循环中间



## Q5：三种范式分别适合什么场景？各举一个例子。
react适合任务信息不确定的场景
计划在执行适合任务信息明确，步骤可见的场景
reflection适合要求答案质量高的场景
