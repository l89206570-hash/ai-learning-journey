# 服装生产流程

## 概述

鑫盛服装厂标准生产流程分为 5 个核心环节：裁剪 → 缝制 → 整烫 → 质检 → 包装。

## 1. 裁剪

- 根据纸样和排版图，使用电剪刀裁剪面料
- 单次可裁 50-80 层，视面料厚度而定
- 裁剪精度误差控制在 ±2mm 以内
- 裁片按码数、颜色分类捆扎，挂标签进下一环节

## 2. 缝制

缝制是整件衣服成型的关键环节，分为多个工序：
- **平缝**：拼接面料主缝（侧缝、肩缝、袖缝），使用平缝机
- **包缝**：锁边处理，防止面料脱丝，使用四线/五线包缝机
- **绷缝**：下摆、袖口卷边，使用绷缝机
- **钉扣/锁眼**：使用专用钉扣机、锁眼机
- 缝制按流水线排布，每道工序有标准工时（SAM）

## 3. 整烫

- 成衣半成品进行熨烫定型
- 大烫：整件成衣最终熨烫
- 小烫：缝制过程中的局部熨烫（口袋、领子、袖口）

## 4. 质检

- 每个工人对自己工序进行自检
- QC 对每件成衣进行 100% 检查
- 检查标准详见 `quality_standards.md`

## 5. 包装

- A 级品：独立挂装 + 防尘袋 + 品牌吊牌
- B 级品：平装折叠 + 塑料包装袋
- 外箱标注：款号、颜色、码数配比、数量、目的地
