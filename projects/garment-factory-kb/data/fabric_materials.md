# 常用面料知识

## 面料分类

### 天然纤维
- **棉 (Cotton)**：吸湿透气，舒适性好，常用于 T 恤、衬衫。易皱，缩水率 3-5%
- **麻 (Linen)**：透气性极佳，夏季首选。手感偏硬，极易皱
- **丝 (Silk)**：光泽好，手感柔滑。需干洗，不耐碱
- **羊毛 (Wool)**：保暖性好，回弹佳。易缩水，需防虫蛀

### 化学纤维
- **涤纶 (Polyester)**：抗皱、快干、挺括。透气性差，易起静电
- **尼龙 (Nylon)**：耐磨、弹性好。怕晒，长期暴晒会变黄
- **氨纶 (Spandex)**：弹性极佳，通常混纺 3-8% 提供弹力
- **粘胶 (Viscose/Rayon)**：手感接近棉，垂感好。湿强度差，缩水率大

### 混纺面料
- **涤棉 (T/C)**：涤纶 + 棉，常见比例 65/35 或 80/20，兼顾挺括和舒适
- **棉氨**：棉 + 氨纶，一般氨纶 3-5%，用于需要弹力的棉质服装

## 面料规格参数

- **克重 (GSM)**：克/平方米，T 恤常用 160-220 GSM
- **纱支 (Yarn Count)**：数字越大纱越细，常用 20S-80S
- **密度**：每英寸经纱/纬纱数量（如 110×70）

## 常见洗涤标签

| 符号 | 含义 |
|------|------|
| 水盆 30℃ | 最高洗涤温度 30℃ |
| 三角 | 可氯漂 / 不可氯漂 |
| 方框圆圈 | 可烘干（点数表示温度）|
| 熨斗 | 可熨烫（点数表示温度上限）|

## 裁剪注意事项

- 针织面料（有弹性）需在松布 24 小时后裁，让面料回缩
- 条格面料裁剪时注意对条对格，损耗增加 3-5%
- 有方向性面料（如灯芯绒）需单向排料，损耗增加 5-8%
